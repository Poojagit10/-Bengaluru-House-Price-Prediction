# Bengaluru House Price Prediction

This project is an end-to-end data science application that predicts house prices in Bengaluru, India. The prediction is served through a web application built with a Flask back-end and a simple HTML/CSS/JS front-end.

## Project Overview
*   **Data Cleaning**: Handled missing values, corrected data types, and removed outliers.
*   **Feature Engineering**: Created new features to improve model accuracy.
*   **Model Building**: Trained a Linear Regression model using Scikit-learn.
*   **API Development**: Built a Flask server to expose the model as a REST API.
*   **Web Application**: Created a user interface for users to get price predictions.

## Technology Stack
*   **Back-End**: Python, Flask, Pandas, NumPy, Scikit-learn
*   **Front-End**: HTML, CSS, JavaScript
